# Prosa 1.4.0

Esta versão acrescenta chamadas diretas de áudio e vídeo, compartilhamento de tela em navegadores compatíveis e uma configuração Docker Compose para hospedar o cliente, a API e o relay TURN no mesmo VPS.

## Antes de usar

- Para mensagens, chamadas e compartilhamento, configure o serviço público conforme [`docs/deployment.md`](../deployment.md) e informe o endereço HTTPS no aplicativo Android.
- O compartilhamento de tela depende do suporte do navegador. Captura de tela Android e chamadas em grupo não estão disponíveis.
- O serviço usa SQLite em uma única máquina. Configure backups fora do VPS; os dados de mensagens não têm criptografia de ponta a ponta.
- Esta versão é adequada a uma implantação de teste controlada. Verificação de e-mail, recuperação de conta e MFA ainda não estão disponíveis.

## Downloads

Os instaladores Windows, Linux e a prévia Android são anexados quando o workflow de release termina com sucesso. O APK Android é de depuração e não é assinado.
