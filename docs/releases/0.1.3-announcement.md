# Prosa 0.1.3

## Novidades

- Fluxos mais claros para conversas recentes, criação e entrada em comunidades.
- Administração de comunidades agrupada por função, com convites, canais e participantes.
- Personalização de nome, identificador, descrição, avatar e moldura.
- Melhorias de rolagem, navegação por teclado, telas pequenas e acessibilidade.
- Preferência de inicialização disponível no Windows e Linux.
- Proteção e expiração de sessões reforçadas no navegador, desktop e Android.

## Downloads

- Windows: instalador `.exe`.
- Linux: pacotes `.deb` e `.AppImage` para x86_64.
- Android: APK de prévia para instalação manual; não é assinado para distribuição pela Play Store.
- O instalador do Windows não tem assinatura de código.

Os pacotes de desktop incluem o serviço local. Para uso entre dispositivos, é necessário configurar uma implantação de servidor conforme o README.
