# Prosa 0.1.2

## Improvements

- Added a browser conversation drawer for narrow screens so people can switch between conversations and channels.
- Added keyboard shortcut handling for conversation search, including platform-appropriate modifier keys and editable-field safeguards.
- Added account options so signing out requires an explicit action.
- Added a live connection indicator and preserved the signed-in state during temporary service/network failures.
- Removed interface controls for features that are not available yet and made the supported emoji picker interactive.
- Improved dialog focus handling, active-navigation semantics, live announcements, touch targets, text readability, and reduced-motion behavior.
- Removed the remote font dependency so the interface renders without a font network request.
- Added Chromium end-to-end coverage for key journeys, responsive widths, keyboard navigation, connection changes, and WCAG accessibility rules.
- Aligned the Android package version with 0.1.2 and advanced its version code to 2.

## Checks

The release workflow builds Windows and Linux desktop packages and an unsigned Android debug preview APK. Android still requires an independently hosted HTTPS API. The APK is for preview and is not signed for store distribution.

The application does not provide email verification, account recovery, multifactor authentication, attachments, video, group calls, or screen sharing. One-to-one audio remains an early feature and TURN support is not configured.
